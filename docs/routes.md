# Маршруты и формы
HTML создаётся на сервере. Чтение — GET. Во всех POST-формах обязательное скрытое поле csrf из токена текущей браузерной сессии. Успешное изменение перенаправляет на страницу результата (303). Гость перенаправляется на /login при открытии защищённой страницы. Ошибки проверки: 400, 401, 403, 404, 409. Данные формы передаются application/x-www-form-urlencoded.

| Метод и путь | Доступ | Вход и результат |
|---|---|---|
| GET / и /masters | Все | service, budget, q, sort; HTML с подходящими активными мастерами |
| GET /masters/<id>, /services, /promotions, /journal | Все | Профиль, услуги, активные акции, текущие тренды и бренды |
| GET, POST /register, /login | Все | name при регистрации, email, password. Успех — cookie beauty_auth |
| POST /logout | Владелец сессии | Удаление login_sessions.jti и cookie |
| GET /book | Клиент, администратор | service, day, необязательный master → группы подходящих окон |
| POST /visits | Клиент, администратор | master, service, day, time; администратор выбирает также client. Сумму определяет сервер |
| GET /cabinet | Вошедшие | История клиента или календарь мастера/администратора по day и period=1/7 |
| POST /visits/<id>/cancel, /complete, /review | По матрице ТЗ | Отмена клиентом/администратором, завершение мастером/администратором, отзыв владельцем |
| GET /manage, /manage/stats | Мастер, администратор | Свой профиль либо выбор мастера администратором. Для отчёта: from, to |
| POST /manage/profile, /tariffs, /shift, /works, /promos, /articles (все с префиксом /manage) | Мастер, администратор | Формы обслуживают собственный профиль или профиль выбранного мастера |
| POST /manage/users, /manage/masters, /manage/services, /manage/trends, /manage/brands | Администратор | Активность пользователя, создание мастера, редактирование услуг и материалов |
| GET /docs | Все | Список фактических путей и методов текущего приложения |
| GET /health | Все | Проверяет подключение к БД; возвращает JSON с status=ok |

Пример для пустой демобазы с действующей скидкой: /?service=2&budget=1500 показывает пустую выдачу для гель-лака; /?service=2&budget=2500 возвращает Анну с ценой 1760 ₽ и Ольгу с её личной ценой. В другой базе возьмите service из формы, ID назначаются PostgreSQL.
