# Beauty Booking · техническое задание
Один салон, местное время Москвы. Клиент выбирает мастера по работе, цене и свободному времени. Главная «Вишня и сливки» поддерживает фильтр по услуге и верхней границе цены, просмотр портретов в ленте и полный каталог. Витрина открыта гостю. Для записи нужен вход. Все цены в рублях.

| № | Требование | Как увидеть результат |
|---|---|---|
| FR01 | Регистрация по email с паролем от 8 символов, новая роль — клиент | Попробовать повторный email, проверить свой кабинет |
| FR02 | Вход, подписанный токен, выход | JWT живёт 8 часов, отзыв сессии при выходе |
| FR03 | Поиск по имени/специализации, фильтр по услуге, бюджету и сортировка | Найти Анну и сравнить выдачу при бюджетах 1500 и 2500 |
| FR04 | Профиль, опыт, услуги, работы, отзывы, средняя оценка | Открыть мастера из каталога |
| FR05 | Услуги по категориям, цены конкретных мастеров и скидки | Раскрыть «Цены мастеров» |
| FR06 | Активные акции со сроком, исходной и новой ценами | Открыть /promotions |
| FR07 | Слоты конкретного мастера с учётом смены и длительности | Услуга полностью помещается в смену |
| FR08 | Любой подходящий мастер на дату | Показать несколько групп свободных окон |
| FR09 | Создание визита, исключение пересечений одного мастера | Из двух конкурирующих подтверждений проходит одно |
| FR10 | Будущие записи, история и отмена клиентом за 2 часа или раньше | Ровно 120 минут разрешены, 119 — отказ |

### Условия приёмки
БД PostgreSQL 16, браузерный интерфейс адаптивный, пароли хранятся как bcrypt-хеши. Используются Flask и шаблоны Jinja. У каждого обработчика изменения есть серверная проверка роли/владельца и CSRF. Обычный запуск — Docker Compose. Публичный каталог, поиск и выдача свободного времени на демоданных: целевое время ответа до 1 с, измерение на машине сдачи документирует Санджи. Справочник маршрутов в docs/routes.md; фактический перечень выводит flask routes. Схема заполняется при создании пустого тома, seed запускается отдельно. Версия для защиты запускается из main на чистой машине.
